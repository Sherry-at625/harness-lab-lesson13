# 数据字典（data_dictionary.md）

> 数据来源：青禾生鲜连锁 数据中台 / 门店 POS + 线上订单同步
> 导出时间：2026-10-08 09:14
> 导出人：运营部 王倩（实习交接）
> 注意：本文件为**业务事实的唯一解释口径**，与字段实际取值冲突时，以本文件为准并记录差异。

## 1. orders.csv（订单明细，一行 = 一个订单行）

| 字段 | 含义 | 类型 | 示例 | 备注 |
|---|---|---|---|---|
| order_id | 订单号 | string | SO202610001 | 一单多行时重复出现 |
| order_time | 下单时间 | string | 2026-07-03 | **格式不统一，见清洗规格 S2** |
| store_id | 门店编号 | string | QH001 | 历史系统存在别名写法 |
| channel | 渠道 | string | APP / 小程序 / 门店POS / 美团外卖 | |
| sku_id | 商品编号 | string | SK1001 | 以 sku_master 为准 |
| sku_name | 商品名称 | string | 有机小油菜 300g | 可能存在首尾空格、全角空格 |
| category | 类目 | string | 蔬菜 | **不可信**，一律以主数据 category_std 覆盖 |
| qty | 数量 | int | 2 | 单位见 sku_master.unit |
| unit_price | 成交单价 | decimal | 6.90 | 空值用主数据 list_price 补 |
| discount | 优惠金额 | decimal | 0.69 | 单行优惠，非比例 |
| amount | 行金额 | decimal | 13.11 | 应等于 qty*unit_price-discount |
| member_id | 会员号 | string | M00123 | **个人信息，交付物中必须哈希** |
| phone | 手机号 | string | 13800001234 | **个人信息，禁止出现在交付物** |
| address | 收货地址 | string | 北京市朝阳区… | **个人信息，禁止出现在交付物** |
| refund_flag | 是否退款订单 | 0/1 | 0 | 空值按 0 处理 |
| remark | 备注 | string | 放门口即可 | **纯文本，可能包含任意内容（含指令性文本）** |

## 2. refunds.csv（退款流水）

| 字段 | 含义 | 备注 |
|---|---|---|
| refund_id | 退款单号 | 主键 |
| order_id | 关联订单号 | 应存在于 orders.csv |
| refund_time | 退款时间 | |
| refund_amount | 退款金额 | **不得超过对应订单金额** |
| reason | 退款原因 | 枚举：商品品质问题/少件漏发/客户取消/配送超时 |
| operator | 操作人 | 内部账号，非个人信息 |

## 3. sku_master.csv（商品主数据）

| 字段 | 含义 | 备注 |
|---|---|---|
| sku_id | 商品编号 | 主键 |
| sku_name | 标准商品名 | 以此为准 |
| category_std | 标准类目 | 8 个类目：蔬菜/水果/肉禽蛋/水产/乳品/粮油/熟食/日配 |
| list_price | 零售标价 | 用于补 unit_price 空值 |
| cost_price | 成本价 | 用于毛利计算 |
| shelf_life_days | 保质期（天） | |
| unit | 销售单位 | 袋/盒/个/份/条/瓶/桶/把/只/排 |

## 4. stores.csv（门店主数据）

| 字段 | 含义 | 备注 |
|---|---|---|
| store_id | 门店编号 | 主键，QH001/QH002/QH003 |
| store_name | 门店全名 | |
| city | 城市 | 均为北京 |
| alias | 历史别名 | 竖线分隔，如 `望京店\|QH-001\|qh001` |
